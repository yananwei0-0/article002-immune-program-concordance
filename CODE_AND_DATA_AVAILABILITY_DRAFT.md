# Code and data availability — controlled release draft

All datasets analyzed in this study are publicly available. Source identities, accession routes, file-level URLs retained by the executed analyses, and checksums are provided in the repository provenance directory. Raw participant-, donor-, cell-, spot-, and facility-level files are not redistributed.

The repository contains the scientific analysis modules required to recompute
the principal CPTAC, TCGA, APOLLO, single-cell/3CA, and spatial result
registries from prepared public-source matrices, together with the locked
consolidated workbook, machine-readable table exports, and code required to
reproduce all main and supplementary figures. Upstream molecular files are not
redistributed, and source download and source-specific preparation are not
fully automated.
