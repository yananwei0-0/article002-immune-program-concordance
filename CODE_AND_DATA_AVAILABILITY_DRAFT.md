# Code and data availability — controlled release draft

All datasets analyzed in this study are publicly available. Source identities, accession routes, file-level URLs retained by the executed analyses, and checksums are provided in the repository provenance directory. Raw participant-, donor-, cell-, spot-, and facility-level files are not redistributed.

The repository contains the locked consolidated results workbook,
machine-readable table exports, and code required to reproduce all main and
supplementary publication figures. It does not contain the upstream raw-data
processing pipeline.

## Blinded-submission wording

The figure- and table-reproducibility package is held in a private versioned
repository during peer review. Reviewer access can be provided in accordance
with journal policy. The public repository and immutable archived DOI will be
released when review-anonymity restrictions permit.
