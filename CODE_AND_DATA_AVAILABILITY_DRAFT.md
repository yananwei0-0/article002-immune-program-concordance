# Code and data availability — release-ready draft

All datasets analyzed in this study are publicly available. Source identities, accession routes, file-level URLs retained by the executed analyses, and checksums are provided in the repository provenance directory. Raw participant-, donor-, cell-, spot-, and facility-level files are not redistributed.

The repository contains the locked consolidated results workbook, machine-readable table exports, and code required to reproduce all main and supplementary publication figures. It does not contain the upstream raw-data processing pipeline. The final public repository URL and archived release DOI will be inserted after the authors approve the license and create the immutable release.
